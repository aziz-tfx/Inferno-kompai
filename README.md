# Inferno — отправка лида с лендинга в amoCRM

Ваша форма на лендинге остаётся как есть, а данные попадают в amoCRM через
**встроенную веб-форму amoCRM**, которую вы создали в кабинете. Это реализовано
**мостом** (`public/amo-bridge.js`): на страницу незаметно подгружается скрытая
amo-форма (её родной скрипт `amoforms.js`), и при отправке вашей формы значения
прогоняются через неё. Реальную отправку в amoCRM делает официальный код amo —
поэтому правила воронки, уведомления и валидация работают штатно.

> **Сервер не нужен.** Всё работает на фронтенде — идеально для лендинга на Vercel.

## Параметры вашей amo-формы

Уже прописаны в `public/amo-bridge.js` (взяты из кода размещения формы):

| Параметр | Значение |
|----------|----------|
| Аккаунт  | `azizcollab.amocrm.ru` |
| Form ID  | `1729890` |
| Hash     | `8cec8b72e4941c9a590219d4bb7cc61a` |

Если создадите другую форму — поменяйте `formId` и `hash` в начале `amo-bridge.js`.

## Как это работает

```
  Ваша видимая форма            Скрытая amo-форма (amoforms.js)
  ┌──────────────┐   submit     ┌──────────────────────┐
  │ Имя          │ ───────────▶ │ копируем значения     │ ──▶ amoCRM
  │ Телефон      │  AmoBridge   │ и жмём «Отправить»    │     Сделка + Контакт
  │ Email        │              └──────────────────────┘     (воронка вашей формы)
  └──────────────┘
```

## Подключение на лендинге (обычный HTML)

1. Положите файл `public/amo-bridge.js` рядом с лендингом (чтобы он был доступен,
   например, по `/amo-bridge.js`).
2. Перед `</body>` подключите скрипт:

   ```html
   <script src="/amo-bridge.js"></script>
   ```

3. В обработчике отправки вашей формы вызовите мост:

   ```html
   <script>
     const form = document.getElementById('lead-form');
     form.addEventListener('submit', async (e) => {
       e.preventDefault();
       await AmoBridge.submit({
         name:    form.name.value,
         phone:   form.phone.value,
         email:   form.email.value,
         message: form.message.value, // необязательно
       });
       form.reset();
       // показать «Спасибо»
     });
   </script>
   ```

Готовый рабочий пример — `public/index.html`.

## Подключение на Next.js (Vercel)

1. Скопируйте `public/amo-bridge.js` в папку `public/` вашего Next-проекта.
2. Используйте компонент из `examples/LeadForm.jsx` (подключает мост через
   `next/script` и вызывает `AmoBridge.submit`).

## API моста

```js
// Опционально — если хотите переопределить параметры формы / таймауты.
AmoBridge.init({ formId, hash, locale, readyTimeout, submitTimeout });

// Отправка данных. Возвращает Promise.
const res = await AmoBridge.submit({ name, phone, email, message });
// res = { ok: true, confirmed: boolean }
//   confirmed === true — amoCRM показала экран «Спасибо» (заявка точно ушла).
//   confirmed === false — сабмит выполнен, но подтверждение не пришло за таймаут.
```

Мост сам сопоставляет ваши поля с полями amo-формы по типу поля (`tel`, `email`),
атрибутам `name`/`placeholder`, `autocomplete` и подписям полей. Имя, если не
нашлось по подсказкам, кладётся в первое свободное текстовое поле.

## Проверка

Локально: `npm start` → откройте `http://localhost:3000`, отправьте форму,
проверьте, что сделка появилась в воронке amoCRM. Или откройте `public/index.html`
на любом хостинге со статикой.

> Мост общается с `forms.amocrm.ru` напрямую из браузера — на локальном
> `http://localhost` amoCRM обычно отвечает нормально; если форма не грузится,
> проверьте, что домен лендинга не заблокирован в настройках формы в amoCRM.

## Альтернатива: серверный API (если однажды понадобится)

В репозитории также есть серверный вариант на Node.js/Express (`server.js`,
`src/amo.js`) — он создаёт сделку + контакт через официальный API amoCRM
(`/api/v4/leads/complex`) по долгосрочному токену. Он **не используется** в
варианте с мостом и нужен, только если вы захотите отправлять лиды со своего
бэкенда, а не через встроенную форму. Настройки — в `.env.example`.
